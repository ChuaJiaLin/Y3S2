# Reflection

## Lab 1 : Alteryx Designer

This lab provided hands-on experience in using Alteryx Designer to configure a workflow and generate the expected output results. It enhanced understanding of how data can be processed, transformed, and analyzed through a visual workflow environment.

Throughout the lab, the process of connecting different tools such as input, preparation, and output components helped build a clearer understanding of data flow and workflow logic. By arranging tools step-by-step, the importance of structuring workflows correctly to ensure accurate results became more apparent. This practical exposure also improved familiarity with data preparation tasks such as filtering, sorting, and data cleaning.

One of the key learning outcomes from this lab is the ability to translate problem requirements into a functional workflow design. It demonstrated how complex data processing tasks can be simplified using drag-and-drop tools without extensive coding. This makes Alteryx a powerful tool for data analytics and automation.

Some challenges were encountered during the lab, particularly in ensuring the correct configuration of each tool and understanding how data changes at each stage of the workflow. However, by reviewing each step carefully and testing outputs incrementally, these challenges were resolved, which improved troubleshooting and debugging skills.

Overall, this lab strengthened practical skills in data processing and workflow development. It also increased confidence in using Alteryx Designer as a tool for solving real-world data problems efficiently and effectively.

## Project: Business Intelligence Analysis of Brazilian E-Commerce Customer Purchasing Behavior Using Olist Datasets

This project has provided valuable experience in applying business intelligence concepts to real-world data. It enhanced understanding of how raw data from multiple sources can be transformed into meaningful insights through data integration, cleaning, and visualization processes.

During the project, several technical challenges were encountered, particularly in data integration and forecasting due to inconsistent data and limited historical records. These challenges highlighted the importance of data quality and careful data preprocessing before conducting analysis.

The use of tools such as Alteryx Designer and Microsoft Power BI also improved technical skills in workflow design, data transformation, and dashboard development. In addition, the project demonstrated how analytical techniques such as segmentation and trend analysis can provide valuable insights into customer behavior and business performance.

Overall, the project strengthened problem-solving skills, critical thinking, and the ability to apply BI techniques to support strategic decision-making.

## Industry Talk (Bridging Data & Decisions: The Role of Data Governance and Data Management in Modern Business Intelligence)

The industry talk provided valuable insights about the importance of data governance in modern 
organizations. A valuable insight discovered was that data governance transforms raw data into 
trustworthy decision-making. Without good data governance, the insights generated are less 
reliable and can affect business performance negatively.  

Another key point from the talk was the main pillars that help to build trustworthy insight. The 
main pillars including data quality, metadata, data lineage, security, and cataloging. These elements 
showed that business intelligence depends on how well the data is managed and maintained.  

Moreover, the talk also related to the topics that were learned in the Business Intelligence course. 
It helped to strengthen the idea that analytics is only useful when data is accurate and properly 
governed. In the current business ecosystem, analytics engineering is important because it helps to 
transform raw data into clear and useful information for reporting and decision-making.  

An inspiring point from the talk was the future use of artificial intelligence (AI) in data governance, 
where AI can help to automate tasks such as checking data quality and detecting inconsistencies 
in data. Overall, the session was very informative and improved the understanding of how data 
governance is related to analytics engineering, and modern business intelligence.
