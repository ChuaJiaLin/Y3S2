## Assignment 1: Technical Report (OLTP VS OLAP)

This project provided valuable understanding of the differences between Online Transaction Processing (OLTP) and Online Analytical Processing (OLAP) systems and their roles in modern data management. Through this report, deeper knowledge was gained regarding how OLTP systems support real-time operations while OLAP systems enable analytical processing and decision-making using historical data.  

The process of researching and comparing both systems enhanced the ability to analyse technical concepts critically, especially in identifying their characteristics, advantages, limitations, and real-world applications. In addition, the project highlighted the importance of integrating OLTP and OLAP systems through data warehouses to achieve both operational efficiency and strategic insights. 

During the development of this report, collaboration within the group improved communication and teamwork skills. The use of academic sources and verification of information also strengthened research and analytical abilities. However, some challenges were faced in understanding complex concepts such as multidimensional data models and data integration processes.

Overall, this project enhanced both theoretical knowledge and practical understanding of database systems and data processing architectures. It also emphasized the importance of combining operational and analytical systems to support effective decision-making in data-driven environments.

## Tutorial 1: Creating Data Pipeline Using Microsoft Azure

Navigation to repository: [End-to-end-Data-Pipeline-Microsoft-Azure-services-](https://github.com/ChuaJiaLin/End-to-end-Data-Pipeline-Microsoft-Azure-services-)  

This project provides hands-on experience in building an end-to-end data pipeline using Microsoft Azure services.
