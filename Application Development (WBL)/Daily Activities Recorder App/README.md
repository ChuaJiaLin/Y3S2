# 📱 Lab 1: Daily Activities Recorder App

## 📝 Overview
The **Daily Activities Recorder App** is a simple Flutter-based mobile application designed to help users input, view, and manage their daily activities. It allows users to add activities with a corresponding time or category, display them in a list, and remove them when needed.

---

## 📝 Reflection

The Daily Activities Recorder App was developed to understand the basic concepts of mobile application development using Flutter. This lab provided hands-on experience in designing a simple user interface and managing user input effectively.

Throughout the development process, important concepts such as the use of widgets, state management using `setState`, and dynamic list display were applied. The app successfully allows users to add and delete activities, demonstrating how user interactions can update the interface in real time.

However, some limitations were identified. The application does not store data permanently, and the user interface is relatively simple. These areas indicate opportunities for improvement in future development.

Overall, this lab was helpful in strengthening foundational programming skills and understanding how Flutter applications are structured. It also provided valuable experience in problem-solving and implementing basic app functionalities.

---

## 🏁 Conclusion

In conclusion, the **Daily Activities Recorder App** is a well-developed beginner project that effectively demonstrates fundamental Flutter concepts. It fulfills its purpose of allowing users to record and manage daily activities with a clean and responsive interface.
